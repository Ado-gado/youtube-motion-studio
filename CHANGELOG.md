# Изменения

## 0.3.0 · 11 октября 2026

- Перенос текущей сцены через motion-job-*.zip без GitHub-аккаунта: упаковка ассетов, шрифтов, звука и параметров, контрольные суммы, локальная очередь, одна копия рендера на одинаковый архив.
- Windows: запуск скрытого обработчика одним CMD, отслеживание папки загрузок, MP4 в LOCAL_RENDER/ready, остановка после текущей сцены. Без глобальной установки и системного автозапуска.
- Быстрый захват непрозрачного 2D Canvas по явному выбору, сохранение скриншотов для DOM/CSS/WebGL, изолированный корень ресурсов, профиль времени рендера. GIF только по отдельному флагу.
- Локальные проверки архива и захвата выполнены без создания новой анимации или повторного ролика с Гагариным. Код history-v2 сохранён; известный остаточный титр документирован.

## 0.2.1

Установка без обязательного демо, текущий заказ вместо повторения Гагарина, готовое видео без сайтов/приложений. Исторический выпуск 0.2.0 сохраняется для истории и не содержит текущих правил.
