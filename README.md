# Documentary Motion Studio

Пакет для создания документальной моушен-графики по свободному описанию, включая диктовку в Emergent. Версия 0.2.0; исходный художественный ориентир — history-v2. Это инструменты и правила работы; новые сцены требуют проверки и реакции автора.

## Установка

После клонирования публичного репозитория в папку проекта:

```bash
python3 scripts/install.py --project-root .
```

Windows: `python scripts/install.py --project-root .`. Требуется Python 3.10+. Установщик создаёт локальную `.venv`, устанавливает Playwright/Pillow/FFmpeg, выбирает имеющийся Chromium либо загружает Chromium Playwright, копирует единственный наш скилл в `.agents/skills` проекта, добавляет указатель в AGENTS.md и запускает doctor. Повторная установка сохраняет остальные инструкции/скиллы. API-ключи не нужны для установки и демонстрации.

Если Linux сообщает о системных библиотеках Chromium, команда для агента: `.venv/bin/python -m playwright install --with-deps chromium`, затем повторный doctor. Не считать установку успешной при ошибке браузера. При отсутствии python3 попросить агента установить Python 3.10+ в своей среде.

## Проверка

```bash
.venv/bin/python scripts/doctor.py
.venv/bin/python scripts/audit.py
.venv/bin/python scripts/render_scene.py examples/history-v2/scene.html --duration 14 --fps 24 --out outputs/history-v2/video.mp4
```

На Windows использовать `.venv/Scripts/python.exe`. Исходные пример и ассеты сохранены из выбранного V2; рендерер переносимый. Папка outputs исключена из Git.

## Использование

Отправить Emergent инструкцию из START_HERE.md, потом говорить задачу обычными словами, например: «Сделай 8 секунд: тёмный архивный фон, вырезанный человек перед ним. Камера приближается, имя появляется из маски. Без звука». Фон, материалы и монтажные приёмы можно уточнять голосом. Если нужны факты, агент проверяет их; числа не придумывает.

Voice Mode — ввод запроса, не озвучка ролика. Для синхронизации приложить запись озвучки отдельно. В новых чатах заново загрузить пакет и прочитать STYLE/FEEDBACK; само присутствие репозитория не гарантирует чтение правил.

STYLE, FEEDBACK, HANDOFF, WORKFLOW и проектный AGENTS можно дополнять под новые решения: их существование проверяется, авторские изменения не считаются повреждением выпуска. Изменения инструментов и исходного демо требуют обновления manifest.json при выпуске новой версии. Пакет хранит правила и замечания в файлах; он не обучает саму модель. Чтобы переносить изменения между аккаунтами, сохранить обновлённые правила в GitHub и читать их в следующем проекте.

## Что включено

Наш локальный скилл, свежие правила, история выбора V2, воспроизводимый пример, шрифты с OFL, переносимые установщик/проверка/экспорт, AE-сборщик и ссылки на выбранные внешние инструменты. Все 15 конкурирующих наборов не активируются одновременно. SAM и платные сервисы устанавливать/подключать при задаче, которой они действительно нужны.

Пример и источники описаны в examples/history-v2/ASSETS.md. README/инструменты не обещают окончательный стиль, реальную историческую 3D-модель или проверенный .aep. Сборщик AE проверяется отдельно в After Effects.

Публикация этого пакета не включает локальные исследования, пользовательские аудиозаписи, отклонённые тесты и чужие инструкции без лицензий. Аудит установки и статус проверок — AUDIT.md.
