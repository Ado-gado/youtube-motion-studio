# Documentary Motion Studio

Публичный репозиторий: [Ado-gado/youtube-motion-studio](https://github.com/Ado-gado/youtube-motion-studio). Готовое первое сообщение для Emergent — [INSTALL_EMERGENT.md](INSTALL_EMERGENT.md).

Пакет для создания документальной моушен-графики по свободному описанию, включая диктовку в Emergent. Версия 0.3.0; исходный художественный ориентир — history-v2. Это инструменты и правила работы; новые сцены требуют проверки и реакции автора.

Автор выбрал простой перенос из нескольких аккаунтов Emergent: скачать **motion-job-*.zip** → местная очередь → готовый MP4 на ПК, без GitHub-логина. [Как запустить и что отправить Emergent](LOCAL_RENDER.md). Пакет не подключает облачный агент к ПК; после скачивания работает локальный обработчик. Рабочие сцены в публичный репозиторий не попадают.

## Установка

Для установки в существующий проект Emergent выполнить из его рабочей папки:

```bash
git clone --depth 1 https://github.com/Ado-gado/youtube-motion-studio.git motion-studio
python3 motion-studio/scripts/install.py --project-root .
```

Команды выполнять по очереди, продолжать только после успешного завершения. Клонирование публичного пакета не требует токена/входа в GitHub. Если пакет уже есть, читать INSTALL_EMERGENT.md; не перезаписывать местные замечания обновлением. Команда получает main со свежими договорённостями; v0.3.0 содержит текущие правила и очередь; v0.2.0 хранит историю с отменённой командой тестового рендера.

После клонирования публичного репозитория в папку проекта:

```bash
python3 scripts/install.py --project-root .
```

Windows: `python scripts/install.py --project-root .`. Требуется Python 3.10+. Установщик создаёт локальную `.venv`, устанавливает Playwright/Pillow/FFmpeg, выбирает имеющийся Chromium либо загружает Chromium Playwright, копирует единственный наш скилл в `.agents/skills` проекта, добавляет указатель в AGENTS.md и запускает doctor. Повторная установка сохраняет остальные инструкции/скиллы. API-ключи не нужны для установки. Установщик не создаёт ролик.

Если Linux сообщает о системных библиотеках Chromium, команда для агента: `.venv/bin/python -m playwright install --with-deps chromium`, затем повторный doctor. Не считать установку успешной при ошибке браузера. При отсутствии python3 попросить агента установить Python 3.10+ в своей среде.

## Проверка

```bash
.venv/bin/python scripts/doctor.py
.venv/bin/python scripts/audit.py
```

На Windows использовать `.venv/Scripts/python.exe`. При установке проверять только инструменты; не экспортировать отдельное демонстрационное видео. examples/history-v2 — архивный референс, не задача на создание клипа. Если задания нет, агент ждёт его. Готовый ролик рендерится по текущему описанию автора; папка outputs исключена из Git.

## Использование

Результат — заказанная моушен-графика в готовом MP4. Без отдельной просьбы не создавать сайты, лендинги, приложения, редакторы, дашборды или деплой. HTML/Canvas может быть внутренним средством рендера; код или ссылка на HTML не являются выполненным заданием. Рабочие исходники хранить в проекте и выдавать по запросу.

В выбранном режиме LOCAL_RENDER облако передаёт разрешённый промежуточный ZIP текущей сцены, а ПК создаёт MP4. В облаке не повторять полный экспорт без просьбы автора. Готовность архива и готовность видео указывать отдельно. На Windows после установки запустить Start_Local_Render.cmd; готовые ролики появятся в LOCAL_RENDER/ready. Результаты технических проверок — AUDIT.md; скорость полной сцены не гарантирована.

Отправить Emergent инструкцию из START_HERE.md, потом говорить задачу обычными словами, например: «Сделай 8 секунд: тёмный архивный фон, вырезанный человек перед ним. Камера приближается, имя появляется из маски. Без звука». Фон, материалы и монтажные приёмы можно уточнять голосом. Если нужны факты, агент проверяет их; числа не придумывает. Сразу создаётся итоговый клип по этому описанию; тесты и альтернативы только по прямой просьбе. От V2 берутся принципы движения, а не Гагарин, его текст, материалы, раскладка и длительность.

Voice Mode — ввод запроса, не озвучка ролика. Для синхронизации приложить запись озвучки отдельно. В новых чатах заново загрузить пакет и прочитать STYLE/FEEDBACK; само присутствие репозитория не гарантирует чтение правил.

STYLE, FEEDBACK, HANDOFF, WORKFLOW и проектный AGENTS можно дополнять под новые решения: их существование проверяется, авторские изменения не считаются повреждением выпуска. Изменения инструментов и исходного демо требуют обновления manifest.json при выпуске новой версии. Пакет хранит правила и замечания в файлах; он не обучает саму модель. Чтобы переносить изменения между аккаунтами, сохранить обновлённые правила в GitHub и читать их в следующем проекте.

## Что включено

Наш локальный скилл, свежие правила, история выбора V2, воспроизводимый пример, шрифты с OFL, переносимые установщик/проверка/экспорт, AE-сборщик и ссылки на выбранные внешние инструменты. Все 15 конкурирующих наборов не активируются одновременно. SAM и платные сервисы устанавливать/подключать при задаче, которой они действительно нужны.

Пример и источники описаны в examples/history-v2/ASSETS.md. README/инструменты не обещают окончательный стиль, реальную историческую 3D-модель или проверенный .aep. Сборщик AE проверяется отдельно в After Effects.

Публикация этого пакета не включает локальные исследования, пользовательские аудиозаписи, отклонённые тесты и чужие инструкции без лицензий. Аудит установки и статус проверок — AUDIT.md.
