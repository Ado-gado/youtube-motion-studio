# Установка в Emergent · 0.4.0

Публичный пакет доступен из разных аккаунтов без входа в GitHub. Скопируй сообщение целиком. Локальное окно редактора запускается на ПК; облако готовит совместимые исходные ZIP.

```text
Я перешёл на локальный редактор Motion Studio 0.4.0. Подготовь ZIP, в котором я сам смогу менять слова, шрифт и время появления/исчезновения надписей, затем соединять фрагменты и рендерить на ПК.

Установи или безопасно обнови пакет из main:
https://github.com/Ado-gado/youtube-motion-studio
Если пакета ещё нет, из текущего проекта:
git clone --depth 1 https://github.com/Ado-gado/youtube-motion-studio.git motion-studio
python3 motion-studio/scripts/install.py --project-root .
Если пакет уже есть, проверь VERSION и git status, сохрани мои сцены/правки, безопасно обнови main и повтори установку. Без reset --hard, clean и удаления моей папки. Скилл только в текущий проект; не глобально.

Прочитай AGENTS.md, STYLE.md, FEEDBACK.md, HANDOFF.md, WORKFLOW.md, EDITOR_SCENES.md, LOCAL_FONTS.md, TEXT_LAYOUT.md и skills/youtube-motion-design/SKILL.md. При установке только doctor/audit; не делать демо, Гагарина или новый тестовый ролик. Если задания ещё нет — сообщи готовность и жди моей диктовки. Если сцена в этом чате уже готова — адаптируй её для редактора, сохранив оформление, тему и движение.

Для текущей заказанной сцены вынеси ВСЕ экранные надписи в motion-editor.json со стабильными id, точными словами, шрифтом, размером, цветом, положением и start/end/enter/exit. Подключи локальную копию runtime/motion-editor.js и действительно рисуй управляемые слои по EDITOR_SCENES.md. Не оставляй те же слова и тайминги зашитыми вторым экземпляром в JS. Правки должны менять кадр, а не только JSON. Не превращай SDK-пример в шаблон композиции. V2 — ориентир глубины и движения, не тема или раскладка для копирования.

Основной шрифт — настоящий Lumios Brush Regular. Он подключается на моём ПК. Не требуй файл Adobe Fonts в облако, не вшивай его в архив, не заменяй молча. Если в облаке его нет, готовь сцену и ZIP со статусом pending_local_verification; финальный текст проверяется на ПК. Текст после раскрытия должен целиком помещаться, с нормальными тенями; не оставлять старые надписи на следующем плане. Перевод, языковые вкладки и озвучку без моего задания не добавлять. Существующий заказанный звук сохранить.

Самостоятельно ищи необходимые реальные фото, модели, фоны, текстуры и правильные иконки. Сохраняй материалы локально, источники/условия/реконструкции — в ASSETS.md и CREDITS.md. Служебные подписи внутрь кадра не добавляй: необходимые отметки я размещу при монтаже.

Упакуй текущую сцену через scripts/pack_scene.py в motion-scene-*.zip: HTML/JS, motion-editor.json, локальные материалы и заказанный звук, ASSETS.md/CREDITS.md, motion-job.json с контрольными суммами. Проверь JSON, ресурсы, доступные кадры и переходы; проверки шрифта, которые не смог выполнить, прямо укажи. Отдай проверенную рабочую ссылку на скачивание ZIP. Не выдавай архив за готовый MP4. Полный облачный рендер не запускай: я импортирую ZIP в местную программу и нажму «Собрать видео». Не включай в архив Python, браузер, node_modules, кадры PNG или пробные видео.

Не создавай сайт, приложение, редактор, авторизацию, БД или деплой в Emergent. Нужен только исходный архив заказанного фрагмента для уже готовой локальной программы. Личные сцены и аудио в публичный GitHub не отправлять.
```
