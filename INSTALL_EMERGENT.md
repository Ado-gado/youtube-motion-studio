# Установка в Emergent

Публичный пакет: https://github.com/Ado-gado/youtube-motion-studio. Читать и клонировать можно без входа в GitHub с разных аккаунтов. Для записи новых правил обратно в репозиторий нужен доступ владельца либо собственная копия репозитория.

Скопировать целиком в новый чат Emergent:

```text
Установи мой пакет документальной моушен-графики:
https://github.com/Ado-gado/youtube-motion-studio

Если этот репозиторий уже импортирован как текущий проект, установи его из корня:
python3 scripts/install.py --project-root .

Если его ещё нет, из рабочей папки текущего проекта выполни по очереди:
git clone --depth 1 https://github.com/Ado-gado/youtube-motion-studio.git motion-studio
python3 motion-studio/scripts/install.py --project-root .

Остановись на ошибке команды и исправь её. Если папка motion-studio уже существует, найди её VERSION и проверь состояние; не удаляй её, не перезаписывай местные замечания. Не устанавливай проектные скиллы глобально.

Прочитай в корне найденного пакета AGENTS.md, skills/youtube-motion-design/SKILL.md, STYLE.md, FEEDBACK.md, HANDOFF.md и WORKFLOW.md. Выполни scripts/doctor.py и scripts/audit.py Python из .venv пакета. Сделай полный тест examples/history-v2/scene.html через scripts/render_scene.py: 14 секунд, 24 fps, 1920×1080, outputs/history-v2/video.mp4. Покажи MP4 и реальные результаты проверок. На Linux при отсутствующих библиотеках Chromium используй Python из .venv: -m playwright install --with-deps chromium, затем повтори doctor. Не утверждай готовность до проверки.

После установки работай как мой моушен-дизайнер для документального ролика. Я буду надиктовывать тему, фон, объекты, текст и движение. Ищи реальные фото, модели, фоны, фактуры и подходящие иконки; сохраняй источники. Ориентир движения и глубины — history-v2. Короткие читаемые надписи, отдельные слои, чистые переходы; не делай презентационные карточки. Диктовка задачи не является озвучкой видео. Звук и нативные редактируемые исходники After Effects — по запросу. Обновляй FEEDBACK/HANDOFF после замечаний; помечай утверждённым только то, что я подтвердил. Мои аудио и рабочие видео не публикуй автоматически. Сохраняй новые сцены в scenes/, экспорты в outputs/ внутри пакета.
```

Команда получает актуальную ветку main. Проверенный исходный выпуск отмечен v0.2.0. Чтобы замечания перешли в другой проект/аккаунт, сохранить обновлённые FEEDBACK/HANDOFF/STYLE в доступную ему копию GitHub. Внутри одного проекта новые чаты читают эти файлы с диска. Установщик не обучает веса модели и не обеспечивает автоматического чтения правил сервисом.

Проверки на Windows выполнены в AUDIT.md; Linux, реальный запуск в Emergent и нативный After Effects здесь не запускались. Импорт проекта через GitHub и Voice Mode описаны в официальных инструкциях, ссылки есть в AUDIT.md.
