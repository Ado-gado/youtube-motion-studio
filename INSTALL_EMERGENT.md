# Установка в Emergent · 0.2.1

Публичный пакет: https://github.com/Ado-gado/youtube-motion-studio. Клонирование доступно без входа в GitHub с разных аккаунтов. Для записи изменений нужен доступ владельца либо собственная копия.

Скопировать целиком в новый чат Emergent:

```text
Установи мой пакет документальной моушен-графики:
https://github.com/Ado-gado/youtube-motion-studio

Если репозиторий уже импортирован как текущий проект, выполни из его корня:
python3 scripts/install.py --project-root .

Если пакета ещё нет, из рабочей папки текущего проекта выполни по очереди:
git clone --depth 1 https://github.com/Ado-gado/youtube-motion-studio.git motion-studio
python3 motion-studio/scripts/install.py --project-root .

Продолжай только после успешной команды; ошибку исправь. Если motion-studio уже существует, найди VERSION и проверь git status. Для старой версии получи изменения main обычным безопасным обновлением; не удаляй папку, не используй git reset --hard/clean и не перезаписывай местные сцены, STYLE/FEEDBACK/HANDOFF. Сохрани локальные изменения и разреши конфликт без потери авторских правил, затем повтори установку. Не устанавливай проектные скиллы глобально.

Прочитай AGENTS.md, skills/youtube-motion-design/SKILL.md, STYLE.md, FEEDBACK.md, HANDOFF.md и WORKFLOW.md в пакете. Для проверки установки запусти только scripts/doctor.py и scripts/audit.py Python из .venv. На Linux при отсутствующих библиотеках Chromium используй Python из .venv: -m playwright install --with-deps chromium, затем повтори doctor. Не рендери тестовый клип или examples/history-v2. Если задания на видео пока нет, сообщи статус установки и жди моего описания.

Мой результат — готовый MP4 с заказанной моушен-графикой. Не создавай сайт, лендинг, приложение, дашборд, редактор, авторизацию, базу данных или деплой без отдельного прямого запроса. HTML/Canvas разрешён только как внутренний источник рендера, не как финальный результат. Исходники и AE bundle отдавай только по запросу, сохраняй рабочие файлы локально.

Я буду надиктовывать тему, фон, объекты, короткие надписи и движение. Делай сразу заказанный итоговый клип, не обязательный тест, не дополнительные варианты и не другую тему. Технически проверяй сам заказанный ролик. Диктовка задания не является озвучкой; без записи голоса готовый клип может быть без звука. Ищи реальные фото, модели, фоны, фактуры и правильные иконки, сохраняй источники. V2 — ориентир глубины, масок и движения камеры, не шаблон сюжета: не копируй Гагарина, 1961, 108 минут, Землю/Восток, текст и композицию примера, если они не нужны в текущем задании. Сцена и тайминг каждый раз строятся под мой запрос. Без задания не выбирай тему самостоятельно.

Отдавай готовый видеофайл; встроенный просмотр этого же MP4 допустим. Не ограничивайся кодом, HTML, ссылкой на сайт или GIF. Обновляй FEEDBACK/HANDOFF после моих замечаний. Звук, исходники и AE — по запросу. Сцены сохраняй в scenes/, видео в outputs/ внутри пакета. Личные аудио и рабочие видео автоматически в публичный GitHub не отправляй.
```

Выпуск 0.2.1 отменяет обязательное воспроизведение Гагарина из стартовой инструкции 0.2.0. В текущем чате действует последнее прямое указание автора; для новых чатов читать main со свежими правилами, не старую метку v0.2.0. v0.2.1 содержит это уточнение. Пакет хранит решения в файлах, не обучает веса модели. Для переноса между аккаунтами сохранить новые правила в доступной им копии GitHub.

В AUDIT.md сохранены результаты исторических технических проверок. Они не являются командой повторять пример. Реальный запуск в Emergent и нативном After Effects здесь не выполнялся.
