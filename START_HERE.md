# Первое сообщение Emergent · 0.3.3

Установи или безопасно обнови мой пакет документальной моушен-графики до версии 0.3.3 из main:
https://github.com/Ado-gado/youtube-motion-studio

Если это текущий репозиторий проекта, запускай из его корня:
python3 scripts/install.py --project-root .
Если пакета ещё нет, из рабочей папки текущего проекта последовательно выполни:
git clone --depth 1 https://github.com/Ado-gado/youtube-motion-studio.git motion-studio
python3 motion-studio/scripts/install.py --project-root .

Если motion-studio уже существует, сначала проверь VERSION и git status, сохрани местные сцены и правила и безопасно обнови main. Не удаляй папку, не используй reset --hard/clean и не перезаписывай мои изменения. После обновления повтори установку. Проектные скиллы устанавливать только в этот проект.

Прочитай AGENTS.md, STYLE.md, FEEDBACK.md, HANDOFF.md, WORKFLOW.md, LOCAL_RENDER.md, LOCAL_FONTS.md, TEXT_LAYOUT.md и skills/youtube-motion-design/SKILL.md в пакете. Для установки выполнить только doctor.py и audit.py Python из .venv. Не рендери пример, Гагарина или тестовый ролик. На Linux отсутствующие библиотеки Chromium исправляй через Python из .venv: -m playwright install --with-deps chromium, затем повтори doctor. Если задания нет, сообщи статус и жди моей диктовки.

Основной экранный шрифт — настоящий Lumios Brush Regular:
https://fonts.adobe.com/fonts/lumios-brush
Он подключается на моём ПК при финальном рендере. Не требуй загрузить файл Adobe Fonts в Emergent, не встраивай его в ZIP/HTML/base64/GitHub и не подменяй шрифт молча. Отсутствие Lumios в облаке не блокирует установку и подготовку сцены. По LOCAL_FONTS.md сохрани local-fonts.json рядом с scene.html, точные надписи — отдельно в редактируемом text.json/config. Сцена должна дождаться MOTION_LOCAL_FONTS_READY, измерить настоящий шрифт, пересчитать строки, маски, тени и положение, затем выставить MOTION_TEXT_LAYOUT_READY=true и READY=true. В облаке не объявляй финальную типографику проверенной: font_status=pending_local_verification, финальные надписи и кадры проверяются на ПК. Доступные материалы, движения объектов и переходы проверь без подмены текстового слоя.

Я надиктовываю тему, фон, объекты, короткие надписи и движение. Создавай только заказанную сцену для документального ролика с глубиной и динамикой. Ищи подходящие фото, модели, фоны, фактуры и правильные иконки в интернете; сохраняй сами материалы и проверенные источники/условия. V2 — ориентир механики движения и масок, не шаблон сюжета, композиции или длительности; Гагарина и элементы примера в чужую тему не копируй. Диктовка не является озвучкой. Звуки и озвучка — по моему заданию. Четыре языковые версии автоматически не создавай.

Полностью появившийся текст должен читаться целиком, без подрезания глифов, диакритики и строк, во всех сценах и языках. После замены текста/шрифта пересчитывать раскладку по TEXT_LAYOUT.md. Не оставлять уходящие подписи поверх нового плана. Проверять сам заказанный клип; отдельные пробные ролики или варианты без моей просьбы не нужны.

Кадры чистые: не добавляй служебные подписи, credits, лицензии, ссылки или «Иллюстративная реконструкция» внутрь сцены. Нужные отметки я поставлю при монтаже. Сохраняй ASSETS.md и готовый CREDITS.md со всеми источниками, условиями, полными атрибуциями и сведениями о реконструкциях; включай их в ZIP. Условия использования материалов остаются обязательными.

Финальный результат — MP4 для монтажа, но экспорт выполняется на моём ПК. После текущего задания упакуй именно заказанную сцену через scripts/pack_scene.py в motion-job-*.zip: HTML/JS, редактируемые надписи, local-fonts.json, материалы и заказанный звук; Adobe-файл шрифта не включать. Отдай настоящую проверенную ссылку «Скачать сцену» на ZIP, проверь GET и motion-job.json. Архив автоматически подхватывает моя местная очередь; честный статус в облаке — «архив готов, локальный рендер ожидается». Полный облачный рендер без просьбы не запускай. При установке ничего не упаковывай.
