# Авторская документальная моушен-графика

Найти пакет в проекте по VERSION 0.2.0 и scripts/install.py; прочитать STYLE.md, FEEDBACK.md и WORKFLOW.md. При копировании этого скилла установщиком корень пакета указан в проектном AGENTS.md. Последнее прямое указание автора важнее файла. Работать в проекте; не устанавливать скиллы глобально.

Это кадры для монтажа, не сайт и не презентация. Свободную диктовку разобрать на событие, фон, объекты, короткий текст и движение. Уточнять только отсутствующий критичный факт. Диктовка задания не является озвучкой ролика. Если озвучки нет — сделать немой тест с явной длительностью.

Главный ориентир — examples/history-v2/scene.html: разная глубина плоских слоёв, камера между соседними композициями, текст поднимается из неподвижной маски с cubic ease-out, короткий бумажный проход перед камерой. Палитра и все детали не утверждены. Для конкретных параметров прочитать references/v2-motion.md. history-v3/plague-v1 не заменяют V2.

Самостоятельно искать нужные фото, модели, фон, фактуры и правильные иконки. Сохранять автора/источник/лицензию/изменения. При генерации обозначать реконструкцию; не выдавать её за запись события. Не придумывать числа и исторические маршруты. Фотографический герой должен быть настоящим отдельным слоем, если глубина требует отделения от фона.

Сохранять версии scenes/<topic>-vNN. До выдачи проверить исходные слова, кириллицу, маски каждой строки, время чтения, совпадение маркеров, отсутствие остаточного текста на новом плане и полное перекрытие кадра при скрытой смене. Проверить соседние кадры каждого перехода. Экспортировать MP4 H.264/yuv420p через переносимый рендерер, показать анимированное превью и дать исходники. Для правил техники читать WORKFLOW. «Код собран», «декодирование прошло», «визуально проверено» и «автор одобрил» — разные статусы.

Редактируемый исходник для автора — файл After Effects со сменой языка. При невозможности создать/проверить .aep дать JSX и все необходимые материалы, отметить отсутствие запуска в AE. Для SFX читать references/audio.md; звук добавлять по запросу.

После реакции автора обновить FEEDBACK/HANDOFF: дата, сцена, замечание, область, изменение и статус. Предложение не помечать approved. Новые чаты должны прочитать свежие файлы; сохранение в рабочем проекте ещё не означает commit GitHub.
