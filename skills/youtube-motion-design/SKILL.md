# Авторская документальная моушен-графика

Найти корень пакета по файлу VERSION и scripts/install.py; прочитать STYLE.md, FEEDBACK.md, HANDOFF.md и WORKFLOW.md. При копировании этого скилла установщиком корень пакета указан в проектном AGENTS.md. Последнее прямое указание автора важнее файла. Работать в проекте; не устанавливать скиллы глобально.

Результат задания — готовый MP4 для монтажа. Не создавать сайт, лендинг, приложение, интерфейс редактора, дашборд, авторизацию, базу данных или деплой без отдельного прямого запроса. HTML/Canvas допустим только как внутренний источник рендера, не как финальный ответ. Рабочие исходники сохранять локально; передавать их и AE bundle только по запросу. Свободную диктовку разобрать на событие, фон, объекты, короткий текст и движение. Уточнять только отсутствующий критичный факт. Диктовка задания не является озвучкой ролика. Без озвучки сделать заказанное видео без звука, с указанной длительностью.

При установке выполнить только doctor/audit: не рендерить отдельный ролик, демо с Гагариным или другой пример. Если задания на видео ещё нет, сообщить статус установки и ждать его. При наличии задания сразу создавать его итоговый монтажный фрагмент. Тесты, альтернативы и дополнительные ролики создавать только по прямой просьбе автора. Техническая проверка кадров заказанного видео обязательна и не требует отдельной пробной анимации.

Ориентир движения V2 — разная глубина плоских слоёв, камера между соседними композициями, текст поднимается из неподвижной маски с cubic ease-out, короткий бумажный проход перед камерой. Для параметров читать references/v2-motion.md; код examples/history-v2/scene.html открывать только при необходимости изучить механизм, не запускать автоматически. Это не шаблон сюжета или раскладки: самостоятельно строить композицию, тайминг и материалы под текущий запрос. Не переносить Гагарина, его портрет, 1961, 108 минут, Землю/Восток и текст примера в чужую тему. Использовать их только если текущая задача требует этих элементов. Палитра и все детали не утверждены; history-v3/plague-v1 не заменяют V2.

Самостоятельно искать нужные фото, модели, фон, фактуры и правильные иконки. Сохранять автора/источник/лицензию/изменения. При генерации обозначать реконструкцию; не выдавать её за запись события. Не придумывать числа и исторические маршруты. Фотографический герой должен быть настоящим отдельным слоем, если глубина требует отделения от фона.

Сохранять версии scenes/<topic>-vNN. До выдачи проверить исходные слова, кириллицу, маски каждой строки, время чтения, совпадение маркеров, отсутствие остаточного текста на новом плане и полное перекрытие кадра при скрытой смене. Проверить соседние кадры каждого перехода. Экспортировать MP4 H.264/yuv420p через переносимый рендерер, проверить декодирование и параметры. Дать готовый видеофайл; встроенный просмотр того же MP4 допустим. Не ограничиваться HTML, кодом, ссылкой на сайт или GIF. Для правил техники читать WORKFLOW. «Код собран», «декодирование прошло», «визуально проверено» и «автор одобрил» — разные статусы.

Если автор отдельно просит редактируемый исходник, это файл After Effects со сменой языка. При невозможности создать/проверить .aep дать JSX и все необходимые материалы, отметить отсутствие запуска в AE. Для SFX читать references/audio.md; звук добавлять по запросу.

После реакции автора обновить FEEDBACK/HANDOFF: дата, сцена, замечание, область, изменение и статус. Предложение не помечать approved. Новые чаты должны прочитать свежие файлы; сохранение в рабочем проекте ещё не означает commit GitHub.
