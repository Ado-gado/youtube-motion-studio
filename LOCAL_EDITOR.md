# Локальный редактор · 0.4.0

Запуск на Windows: **Start_Motion_Editor.cmd** в папке установленного пакета. На этом ПК Python и движок уже подготовлены. На новом ПК сначала выполнить `python scripts/install.py --project-root .`. При первом запуске редактор добавляет в местную `.venv` небольшую библиотеку перетаскивания ZIP; глобальные установки не нужны.

## Работа

1. Скачай `motion-scene-*.zip` из Emergent. Сохрани архивы в папке своего фильма, чтобы случайно не удалить их при очистке «Загрузок».
2. Перетащи один или несколько ZIP в окно либо нажми «Добавить ZIP». Одинаковый архив не добавляется повторно; для повторения сцены есть «Дублировать фрагмент».
3. Выбери сцену слева, надпись справа. Меняй слова, шрифт, размер, цвет и положение. Нажми «Применить и показать». Текст можно вручную ввести на любом языке; перевод программа не выполняет.
4. Передвигай полосу надписи на шкале либо её края. «Начало» — первый момент появления; «Конец» — полное исчезновение. «Вход» и «Выход» — длительность соответствующей анимации внутри этого интервала. Значения можно ввести цифрами, с точкой или запятой.
5. Поменяй порядок фрагментов стрелками. «Сохранить» записывает маленький `.motion.json`; «Сохранить как» позволяет сделать другую текстовую версию с теми же исходными ZIP.
6. «Рендер фрагмента» экспортирует выбранную сцену. «Собрать видео» рендерит сцены по порядку и соединяет MP4. Готовность подтверждается только после проверки декодирования. Посмотри конечное видео перед использованием.

Рядом с MP4 сохраняются `.checks.json`, `.ASSETS.md` и `.CREDITS.md`. Отметки авторства не рисуются внутри кадров. Встроенный в архив звук сохраняется; в последовательности беззвучных и звучащих сцен беззвучные участки получают тишину.

## Диск

Исходные ZIP не копируются в программу и не меняются. Предпросмотр читает ресурсы прямо из архива. Проект хранит пути, контрольные суммы, порядок и правки. Дубликаты сцен и текстовые версии используют те же ZIP. Архивы не удаляются автоматически: они нужны при следующем открытии. После перемещения архива нажми «Найти перемещённый ZIP».

При экспорте во временную папку распаковывается только текущая сцена. После неё распаковка удаляется; остаётся временный сжатый промежуточный MP4 для сборки. После завершения, обычной ошибки или отмены эти промежуточные файлы удаляются. Кадры PNG на диск не складываются. Финальный MP4 хранится там, где ты выбрал. Если выбрать существующее имя, успешный экспорт заменит этот файл; при ошибке существующий MP4 сохраняется.

Нужное свободное место во время работы: одна распакованная сцена + промежуточные сжатые клипы + итоговый файл. После аварийного выключения ПК временные остатки могут сохраниться в `EDITOR_WORK/temp`; не удаляй их во время активного рендера. Автоматической библиотеки копий и постоянного видеокеша в этой версии нет; повторный полный экспорт снова рендерит все сцены. Размер тяжёлых исходников и готовых видео зависит от материалов.

Проверка на 50 записях с общим архивом: файл проекта 53 318 байт. Это проверка хранения, не обещание скорости для 50 тяжёлых 3D-сцен.

## Совместимость и границы версии

- Нужен исходный ZIP с `motion-job.json`, `motion-editor.json` и подключённым кодом сцены по **EDITOR_SCENES.md**. Произвольный MP4 не содержит редактируемых слов.
- Старые motion-job ZIP доступны для просмотра и экспорта. Если текст зашит в JavaScript, попроси Emergent адаптировать существующую сцену, сохранив её оформление. Редактор сообщает об отсутствии поддержки правок.
- В списке шрифтов показаны семейства Windows; окончательную доступность проверяет Chromium. Lumios Brush не вложен в пакет и на этом ПК ещё не подтверждён. Если он недоступен, будет сообщение; молчаливой замены нет. Можно явно выбрать другой установленный шрифт.
- Программа меняет объявленные текстовые слои. Длительность всей сцены, движение камеры, изображения и сложные эффекты меняются в исходной сцене через Emergent. Шкала относится к выбранному фрагменту; сборка соединяет фрагменты прямой склейкой, без новых переходов между ними.
- Предпросмотр без звука, показывает кадры по мере готовности и может пропускать их на тяжёлой сцене. Экспорт считает каждый кадр. Автоматический перевод, озвучка и языковые вкладки не подключаются.
- Сцена сохраняет собственный размер и fps при рендере; при сборке приводится к размеру/fps первого фрагмента, с полями при другом соотношении сторон. При различии параметров или наличии звука промежуточные MP4 кодируются для совместимости.
- Открытие редактора останавливает прежнюю автоматическую очередь после текущего задания. Новые `motion-scene-*` не запускают автоматический рендер из «Загрузок». Экспорт начинается по кнопке.

Кнопка «Инструкция для Emergent» копирует **EDITOR_EMERGENT_MESSAGE.txt**. Для нового чата можно отправить **START_HERE.md** целиком. GitHub-аккаунт для скачивания публичного пакета не требуется.
