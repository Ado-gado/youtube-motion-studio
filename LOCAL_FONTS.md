# Шрифт на ПК, сцена из Emergent

Текущий режим автора — локальный редактор (0.4.0, 11 октября 2026). Он вручную меняет слова, шрифт и тайминги, располагает много ZIP-фрагментов по порядку и нажимает экспорт MP4. Читать EDITOR_SCENES.md и LOCAL_EDITOR.md из корня пакета. Emergent готовит исходный motion-scene-*.zip с настоящим подключением motion-editor.json и runtime/motion-editor.js; автоматический рендер при скачивании больше не основной путь. Старые указания motion-job/очереди ниже относятся к прежнему режиму и действуют только по отдельному выбору автора. Создание локальной программы явно разрешено; это не разрешение строить новый сайт или редактор в Emergent. Без автоматического перевода, языковых вкладок и общей дорожки озвучки; исходный заказанный звук сохранять. ZIP не является готовым MP4. Старую сцену адаптировать без смены её темы/оформления. Установку завершать doctor/audit, без творческого тестового видео.

Основной экранный шрифт автора — **Lumios Brush Regular**. Он остаётся на компьютере финального рендера. Отсутствие Lumios в облаке не блокирует установку, doctor/audit, сбор материалов, движения и упаковку сцены. Не просить загрузить файл Adobe Fonts в Emergent; не встраивать его в ZIP, HTML/base64 или GitHub. Не заменять семейство молча.

## Один раз на Windows

При наличии подходящего доступа Adobe Fonts добавить Lumios Brush Regular на [странице семейства](https://fonts.adobe.com/fonts/lumios-brush) и активировать через Creative Cloud. Для приложений вне Adobe может потребоваться **Install** в разделе Added Fonts. Затем запустить `Check_Local_Font.cmd` в корне пакета. Проверяется именно Chromium нашего экспортера: успешная активация в Adobe сама по себе не подтверждает доступность в нём. Пока Lumios недоступен, готовый клип с этим шрифтом не обещать.

Проверка загружает отдельный `FontFace` с `local()` и ждёт `load()`. Она не полагается только на `document.fonts.check()`, который может разрешить запасной шрифт. Файл шрифта не извлекается, не копируется и не отправляется в облако. Документация: [FontFace](https://developer.mozilla.org/en-US/docs/Web/API/FontFace/FontFace), [load()](https://developer.mozilla.org/en-US/docs/Web/API/FontFace/load).

## Что обязан подготовить Emergent

Для новой сцены с выбранным шрифтом положить **local-fonts.json рядом с scene.html**:

```json
{
  "schema": 1,
  "fonts": [{
    "family": "Lumios Brush",
    "sources": ["Lumios Brush", "Lumios Brush Regular"],
    "weight": "400",
    "style": "normal"
  }]
}
```

`family` — имя, используемое сценой в CSS/Canvas. `sources` — имена настоящего локального семейства/начертания; запасные семейства в список не добавлять. Не выдумывать Adobe PostScript ID. Рендерер читает этот JSON автоматически и перед запуском сцены задаёт `window.MOTION_LOCAL_FONTS_READY`. Сцена должна дождаться этого Promise **до измерения текста**, загрузить свой редактируемый текст из `text.json`/config, затем заново рассчитать строки, глифы, маски, тени и положение относительно камеры по TEXT_LAYOUT.md.

Порядок инициализации:

```js
async function initialize() {
  try {
    if (!window.MOTION_LOCAL_FONTS_READY) {
      throw new Error('Desktop font binding is required; final text preview is pending PC rendering');
    }
    await window.MOTION_LOCAL_FONTS_READY;
    await loadSceneAssetsAndText(); // функция текущей сцены
    recalculateTextLayout();        // фактические metrics; не заранее записанные размеры
    window.MOTION_TEXT_LAYOUT_READY = true;
    window.READY = true;
    await window.seek(0);
  } catch (error) {
    window.ERROR = String(error.message || error);
  }
}
```

Это контракт инициализации, не готовый шаблон ролика. Самостоятельно реализовать загрузку/раскладку для конкретной сцены. Canvas: `ctx.font = '400 120px "Lumios Brush"'` с выбранным размером; CSS: `font-family: "Lumios Brush"; font-weight: 400; font-synthesis: none`. Не рисовать Regular искусственным жирным. Маски появления рассчитывать по реальным глифам и завершать полным читаемым состоянием.

Если облако не имеет настоящего Lumios, проверять только доступные материалы, тайминг/геометрию объектов и переходы. Для диагностики можно отключить слой текста; не создавать замену шрифта и не выдавать такую проверку за финальную проверку типографики. В HANDOFF и brief/config записать `font_status: pending_local_verification` и отдельно: финальные надписи/раскладка/кадры MP4 ещё требуют проверки на ПК. Отсутствие шрифта не повод прекратить подготовку ZIP. После упаковки JSON и редактируемый текст должны присутствовать в архиве; сам Adobe-файл — отсутствовать.

ПК не переводит текст автоматически: берёт точные строки из конфигурации сцены. Их можно изменить до повторного рендера, если сцена реализует чтение config и пересчёт раскладки. MP4 содержит уже нарисованный текст; редактирование исходника требует нового экспорта. Автоматический перевод и четыре языковые версии не запускать без задания.

## Что делает экспорт

`render_scene.py` автоматически обнаруживает local-fonts.json, загружает заявленные шрифты из системы и останавливает экспорт при отсутствии настоящего семейства. До захвата требует `MOTION_TEXT_LAYOUT_READY=true`; в checks.json записывает результат подключения. Флаг подтверждает выполнение контракта сцены, а не автоматически доказывает художественную читаемость всех кадров: контрольные кадры и MP4 всё равно просмотреть.

`pack_scene.py` проверяет JSON, включает его как обычный файл сцены и сообщает desktop_fonts_required. Упаковка выполняется стандартным Python без установки шрифта и Playwright. Старые сцены без local-fonts.json сохраняют прежнее поведение; новая возможность не меняет автоматически шрифт в ранее скачанном Гагарине.

Если архив попал в очередь до активации шрифта, задание останется с ошибкой и логом, готовым оно не считается. После исправления запустить `Retry_Local_Render.cmd`, затем `Start_Local_Render.cmd`, если очередь остановлена: повторятся только неудачные задания, готовые видео повторно не рендерятся.
