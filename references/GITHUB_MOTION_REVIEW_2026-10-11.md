## Что корректировать в рекламном описании

Все 15 ссылок открылись. Указание «13 навыков» у charlie947 уже расходится с README (14); student-kit сейчас пишет 15. Рекомендация Opus 5.5 действительно встречается в README charlie947, а howseen заявляет такой пример, но доступность модели и сравнительное преимущество здесь не проверялись. Установка навыков не обучает веса модели и не доказывает качество результата. Официальные аккаунты подтверждают происхождение проектов, но не авторство и качество каждого правила сообщества.

## Предлагаемый порядок

1. Изучить реальный исходник и движение history-v2, измерить появление текста, перекрытия, темп камеры, паузы чтения; сохранить конкретные параметры, а не слово «cinematic».
2. Отдельно разобрать reference-to-motion (charlie947), review-loop (claude-motion), choreography (LottieFiles), camera/blur (howseen). Это кандидаты, не уже внедрённые правила.
3. Для следующей маленькой пробы сохранить материал и характер V2; менять только один аспект, например появление одного короткого названия. Проверять начало/середину/конец появления и читаемый hold, а также движение между ними.
4. object-separation использовать при реальной потребности в видеовырезке; качество края проверить на исходнике. Для фотографии может хватить более лёгкого инструмента.
5. Выбрать один движок экспорта: текущий HTML или HyperFrames; Remotion рассматривать отдельно. Не устанавливать все конкурирующие наборы одновременно.

## Emergent и After Effects

Claude-специфичные команды установки не считать работающими в Emergent автоматически. Переносимые правила, локальные файлы стиля и параметры движения можно передавать как контекст; запуск Node/Python/ffmpeg зависит от доступной среды и не проверен этим обзором. Ни один просмотренный README не подтвердил готовый экспорт в нативный .aep с редактируемым текстом. Наш JSX-сборщик остаётся отдельной задачей и требует проверки в AE. Не заменять его React/HTML-исходником под названием «файл AE».

Ничего не установлено глобально или локально, V2 и основной стиль не переписаны. Отчёт сохранён локально; в GitHub не опубликован.
